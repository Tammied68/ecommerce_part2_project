# eCommerce REST API

## Overview
This project extends a Django eCommerce application by implementing a **RESTful API** that allows vendors and buyers to interact with stores and products programmatically.

The API supports:
- Retrieving store information  
- Retrieving products for a store  
- Allowing vendors to add products to their stores  

This project was developed as part of the **HyperionDev AI Bootcamp – eCommerce Assignment (Part 2)**.

## Technologies
- Python
- Django
- Django REST Framework
- **MariaDB** (used as the database backend per assignment requirements; replaced SQLite)
